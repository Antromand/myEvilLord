# ADR-0001: Godot как игровой движок

- Статус: принято
- Дата: 2026-08-30

## Контекст

Проект — 2D-игра для ПК, вдохновлённая *What Did I Do to Deserve This, My Lord!?*. Разработка будет итеративной: сначала проверяем игровой цикл в небольшом graybox-прототипе, затем углубляем дизайн по результатам тестов.

Для проекта важны сильные встроенные 2D-инструменты, быстрая сборка прототипов, возможность автоматизированной работы агента с текстовыми файлами проекта и отсутствие роялти.

## Решение

Использовать Godot 4 и GDScript. Базовая версия первого playable-прототипа — Godot 4.7.2-stable. Целевые платформы первого этапа — Windows и другие настольные ОС, если это не увеличивает объём прототипа.

Сцены и ресурсы по возможности хранить в текстовых форматах Godot (`.tscn`, `.tres`), а игровую логику — в небольших тестируемых скриптах. Обновление движка выполнять отдельным проверяемым изменением после повторного запуска smoke-тестов.

## Следствие

Первый технический срез создаётся непосредственно в Godot. Финальный арт, сложная архитектура и широкий набор механик откладываются до проверки основного игрового цикла.
